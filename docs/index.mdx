Kache reuses matching compiler outputs for Rust, C/C++, and CUDA. Keep using your
build tools; Kache restores eligible work from a shared local store and compiles
the rest. Optional remote storage shares that work between machines.

## Start with a local build

These docs follow v2 on `main`. To use the published v2 preview:

```bash
cargo install kache --locked --version 2.0.0-rc.3
kache init
kache doctor --probe
cargo build
```

An unversioned install selects the stable channel. Optional Blaze routing is
available from RC.3. The [upgrade guide](/docs/getting-started/upgrade-v2) maps the versions
and explains the paired `kache`/`kache-engine` installation.

You need Rust 1.95 or newer to install through Cargo. Prebuilt packages are
available in the [installation guide](/docs/getting-started/installation).
`kache init` shows its setup plan before applying changes.

A fresh cache needs a build to fill it. If Cargo already has up-to-date outputs,
it skips the compiler and Kache has nothing to restore. Follow the
[quick start](/docs/getting-started/quick-start) to verify reuse in two worktrees
with separate target directories.

## Current support

| Area | Support |
| --- | --- |
| Rust libraries | Linux, macOS, and Windows |
| Rust executables, test binaries and build scripts | Cached by default on Linux and macOS, off by default on Windows (`cache_executables`). Build-script runs are cached on Linux and macOS |
| C and C++ object compilation | GCC, Clang, Apple Clang, and clang-cl. MSVC `cl.exe` is not cached |
| CUDA object compilation | Single-source `nvcc -c` and `-dc` |
| Rust documentation | Unix with compatible Cargo versions and [unstable rustdoc flags](/docs/getting-started/rustdoc). Rust 1.99 and Windows pass through |
| Local cache | Content-addressed storage with automatic garbage collection |
| Remote cache | S3-compatible storage, GCS, filesystems, and OCI registries |
| Build visibility | Live monitor, stats, miss explanations, and reports |
| Incremental edits | Managed target-local state and compatible donor seeds with supported rustc 1.98+ |
| Optional Blaze routing | Main only; local default-profile commands on Linux and Apple silicon macOS |

Kache passes unsupported compiler invocations through unchanged. A passthrough is not a cache hit or miss. Its reason appears in the monitor's Why tab and in the Not cached section of `kache stats --full`.
